# Official WARDOGS map previews

The images `bakurani.webp`, `ozeti.webp` and `zestafona.webp` are © BULKHEAD / WARDOGS. They are unmodified DayStartClear 1280×720 previews from the official WARDOGS RCON console, mirrored by the community WARCON project at https://github.com/warcon-app/warcon under `static/maps/`.

Map names: Bakurani = Kavkazi, Ozeti = Europe, Zestafona = NorthAmerica.

These game images are **not** covered by the MIT license for WARCON's source code, and 1ADAAR makes no ownership or endorsement claim. They are used only to identify maps for the WARDOGS community server's recorded match reporting, consistent with the administration-context attribution published at https://github.com/warcon-app/warcon/blob/main/static/maps/ATTRIBUTION.md. Honor any BULKHEAD / Team17 removal request.

The art is never used to infer a live player location, map rotation or unrecorded match results.
