## Finished integration hooks (not live art)

- The map-performance page can display locally packaged, approved map art behind its map results rows.
- The real Python Discord recap renderer prefers a matching local banner for the recorded map. If unavailable, it retains the current official generic hero art.
- The exact supported map names are Bakurani, Ozeti and Zestafona. Unknown names or unapproved filenames fall back safely to the existing look; no network fetches or unsourced replacements.
- `docs/assets/map-banners/manifest.json` remains empty by default, so no third-party image is displayed.
- To activate a particular map **after checking the press kit / obtaining permission**: place its optimized landscape WebP under `docs/assets/map-banners/<map-lowercase>.webp`, add `"<Map Name>": "<map-lowercase>.webp"` to `manifest.json`, credit WARDOGS / BULKHEAD / Team17, test both the map page and generated Discord card.
- Use an image without baked-in big map titles when possible; the interface and recap already render the confirmed map name. This avoids unreadable duplicated lettering at mobile sizes.
- Keep an unmodified source copy in private design storage only if licensing allows; export sized, optimized visuals for the public repository. No private game assets or unapproved datamined game files.

## Acceptance

1. Check publisher press kit for named-map stills and usage guidance. Ask BULKHEAD / Team17 if unclear whether independently hosted community dashboards and Discord recaps qualify under the media permissions.
2. Inspect pixel quality for desktop 1440px and Discord 1080px, including helicopter/visual overlap, map label contrast and compression.
3. Confirm exact `WARCON map` name normalization; never substitute a Bakurani image for an unsupported map.
4. Run existing tests and six-width screenshots with at least one activated banner before merging.
5. Keep image content distinct from 16k/32k tactical map terrain captures; those are for spatial planning, not necessarily legal or useful as report banners.
