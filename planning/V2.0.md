# 1ADAAR v2.0 — build started 2026-10-20

**Working branch:** `staging/v2.0-foundation`
**Release rule:** v1.0.1 remains production. No partial v2 feature is public until the owner approves a reviewed merge and its checks pass.

## Why start now?

The public WARCON all-time player index already exists. We can improve real player experiences immediately without waiting for match history. Likewise, recording completed matches permanently should start **before** we collect enough for the 120-match rolling window to lose older records.

## Implemented in this first v2 branch

1. **Permanent captured-match archive**: `src/season_archive.py` keeps the already-public, whitelisted, completed match objects beyond the homepage's 120-match window. Each official season/month is a separate compact JSON file under `docs/data/seasons/<seasonKey>/<YYYY-MM>.json`. A small index lists the captured seasons/months and counts. The collector reuses the same WARCON fetch; no new host, API token or per-visitor request.
2. **Integrity checks**: Previously saved results cannot silently be overwritten by conflicting data. Incomplete/abandoned matches, invalid keys and untrusted external links are rejected. Raw Steam IDs, roster fields and join codes are not copied into the archive. Missing prior matches cannot be recreated.
3. **Compare two real players**: `docs/compare.html` reads `data/players.json` locally in the browser, showing all-time WARCON kills, deaths, matches, wins, playtime, K/D (only when deaths are nonzero), win rate and conditional combat stats. It has shareable pseudonymous-key links, usable phone layout, keyboard controls, and no imaginary demo player.
4. **Plain-English navigation** to comparisons from the home, player, sample and weekly pages. All v2 changes remain in a draft PR; public pages continue showing v1.0.1.

## Boundaries that must remain honest

- **Captured history isn't complete match history.** Matches missed by GitHub Actions or not available from WARCON can't be retroactively reconstructed. Each archive manifest records `coverage: captured-only`.
- **All-time isn't this season.** We must not compute a season K/D from all-time totals. Real season-specific WARCON fetches and known season dates are a separate planned milestone.
- **Player IDs are pseudonymous, not anonymous.** The SHA256 key is reusable and may be guessed from candidate Steam IDs. Do not publicly show raw Steam IDs, use hashes as an authentication method, or claim one player's stats are private.
- **Only known season boundaries can be assigned.** Keep the official season-start data updated and reviewed when WARCON starts a new season; do not guess rankings or character levels from dates.
- **No guaranteed minute-precise collector runs** on GitHub Actions.
- **No new infrastructure:** GitHub Pages, repository data, GitHub Actions and the public WARCON API only.

## Next development increments

- **v2.0 candidate:** Add server-level season-specific WARCON player rankings (`range=s:<official-season-key>`), supported by schema tests, accurate data-source labels and a fallback when WARCON's public API lacks season stats. Integrate into player pages as a distinct season selector. Never substitute all-time totals.
- **v2.0 candidate:** Browsable older matches using the captured-season manifest; mobile filters, lightweight paging and direct public WARCON citations. No need to preload every match.
- **v2.0 candidate:** Per-player personal bests based only on archived matches actually containing verified player results, labeled as *personal best among saved matches*.
- **v2.1:** Richer map/team comparisons and shareable player graphics, only with genuinely supported measurements.
- **v2.2:** Admin-only service health notifications and community achievements, opt-in and with duplicate prevention.

## Acceptance before release

- Full Python + JavaScript tests pass on the exact candidate SHA.
- Collector remains safe with zero real completed matches and retains the first genuine match across repeated runs.
- Archive preserves old captured matches after the front-page 120 cap rolls forward, without duplicates or personal IDs.
- Full live desktop/mobile visual check of compare page and source-labeled stats.
- Verify future WARCON season dates and real match detail fields before labeling any results season-specific.
- No merge into main without approval. v1.0.1 stays deployable and has a rollback branch.
