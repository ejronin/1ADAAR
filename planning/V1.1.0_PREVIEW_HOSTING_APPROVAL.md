Build a test of JS/CSS/JSON paths at the actual deployed origin. GitHub Docs: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

### B — Cloudflare Pages branch preview (useful if Tier 2 Steam consent planned)

Authorize an eligible Cloudflare account, connect `ejronin/1ADAAR` repository with narrow GitHub permissions, set the application output directory to `docs`, identify `feature/v1.1-ia-implementation` as the explicitly controlled preview branch and prevent accidental deployment from `main` to a second public "production" URL.
